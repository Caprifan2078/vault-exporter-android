# Vault Exporter — Android QA APK без GitHub Secrets

Эта ветка `qa/runtime-api-test-account-20261102` добавляет **отдельную экспериментальную APK** `org.vault.exporter.runtimeqa`. Это не релиз.

## Зачем

Предыдущая QA сборка требовала предварительной настройки `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` в GitHub, хотя владелец не хотел использовать основные аккаунты и создавать там API-приложение. В новой сборке отсутствуют встроенные API-ключи: их можно ввести **на самом телефоне**, когда появятся реквизиты от изолированного тестового аккаунта/отдельного приложения разработчика.

## Порядок работы на телефоне

1. Установить `VaultExporter_REAL_TG_RUNTIME_QA_20261102.apk` из GitHub Actions QA **после успешной сборки и проверки хэша**.
2. Нажать «Сначала проверить TDLib без аккаунта». Дождаться надписи `TDLIB_OFFLINE_PROBE_PASS`. Это не отправляет сообщения Telegram.
3. Нажать «Подключить настоящий Telegram». Приложение предложит ввести **API ID и API Hash**, которые были получены у Telegram для отдельного зарегистрированного приложения разработчика. Эти значения не нужно отправлять в чат или GitHub.
4. После предупреждения и явного подтверждения можно ввести номер **только отдельного подконтрольного тестового аккаунта**. Коды, email и 2FA могут потребоваться; ни один из них не должен попадать в GitHub или ChatGPT.
5. Для проверки использовать искусственные переписки, потом проверить `.tva`, целостность медиа и восстановление после обрыва.

## Состояние

- TDLib native был успешно собран и проверен в GitHub Actions (офлайн-APK, 02.11.2026).
- QA-runtime APK собирается с использованием бинарника TDLib из проверенной исходной офлайн-сборки; отдельный GitHub Actions запуск `qa-runtime-apk.yml`.
- Реального логина и выгрузки Telegram **пока не было**, audit сети на реальном Android не проведён.
- Нет гарантии, что купленный дешёвый аккаунт позволит зарегистрировать API-приложение. Покупка не рекомендована до полной проверки APK.
- Учётные данные API вводятся только в память Activity и сбрасываются при её уничтожении. TDLib отдельно хранит данные сессии/кэш в приватном хранилище приложения; при выходе сессия должна очищаться.
- Не использовать основной Telegram и не выдавать APK как безопасную публичную версию.
