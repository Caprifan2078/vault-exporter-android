# Учебный экспорт без Telegram

Эта ветка содержит испытательный режим Vault Exporter для обычного пользователя.

## Что нажать на Android
1. Установить APK из артефакта GitHub Actions, если сборка помечена успешной.
2. Открыть Vault Exporter.
3. Нажать «Попробовать без аккаунта: скачать учебный чат».
4. Нажать «Скачать учебный чат» и выбрать **локальную** папку Downloads.
5. Получить ZIP. После распаковки в нём будут `messages.html`, `manifest.json`, страницы JSONL и папка `media`.

## Что происходит технически
- Внутри приложения генерируются 60 вымышленных сообщений и 7 учебных вложений.
- `LocalMockTdlib` отвечает на те же команды `getChatHistory`, `downloadFile`, `deleteFile` и `getChat`, которые ExportEngine посылает реальной TDLib.
- **Тот же** `ExportEngine` делает постраничную выгрузку, складывает зашифрованные промежуточные данные через Android Keystore, удаляет временные незашифрованные файлы и формирует HTML ZIP.
- Готовый ZIP проверяется `HtmlArchiveWriter.verify`. Промежуточный зашифрованный прогресс удаляется.
- Режим только в test-DC сборке. Подключение Telegram не требуется. Внешних сетевых запросов этот режим не выполняет.

## Что не доказано
Это НЕ проверка входа в Telegram, реальных API-ответов, загрузки реальных облачных медиа, работоспособности нативного клиента на всех Android и отсутствия риска ограничений Telegram. Нулевой риск нельзя гарантировать. Устанавливать этот APK ради выгрузки личных переписок нельзя.

## О приватности
У учебного ZIP нет шифрования, потому что там нет реальных данных. Настоящий экспорт по умолчанию использует парольный TVA; публикацию личного HTML ZIP следует сопровождать предупреждением о его открытом содержимом. Тестовая ветка никак не затрагивает `main` и не использует личные учётные данные.
