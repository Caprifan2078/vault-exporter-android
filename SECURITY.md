# Vault Exporter: политика безопасности

- Разработка ведётся в PRIVATE-репозитории.
- Не загружать сюда реальные переписки, номера телефонов, коды входа, пароли, файлы сессий или исходные архивы пользователей.
- Доступ к исходникам имеют владелец, одобренные участники и установленные GitHub-приложения. Private не означает, что инфраструктура GitHub не обрабатывает код.
- Сборки GitHub Actions выполняют тесты на искусственных данных. Telegram-аккаунты в CI не используются.
- Вход в реальный Telegram запрещён в тестовой конфигурации экспортёра.
- Никаких сторонних серверов экспорта, логирования переписок или аналитики.
- Не публиковать Actions-артефакты в открытых Releases.
- Не использовать основной аккаунт для испытаний непроверенного приложения.
- Перед реальным использованием необходимы аудит зависимостей, APK, сетевого трафика, хранения ключей, корректного завершения сессий и тесты полноты экспорта.
- Блокировки Telegram невозможно гарантированно исключить.

Статус: прототип. Не применять к критически важным данным.
