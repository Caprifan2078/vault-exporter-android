# Vault Exporter — приватный Android-проект

**Статус:** разработка / не готов к использованию с важными Telegram-аккаунтами.

## Приватность
Репозиторий должен оставаться PRIVATE. Не загружайте Telegram-коды, пароли, ключи API, файлы сессий или настоящие переписки. Сборочный GitHub CI не должен подключаться к личным Telegram-аккаунтам.

## Следующий шаг
1. Скачайте из чата с ChatGPT `Vault-Exporter-Android-v09-source.zip` (прошедший локальные офлайн-тесты).
2. На странице этого **приватного** репозитория: Add file → Upload files. Загрузите ZIP целиком с тем же названием, без распаковки.
3. Нажмите Commit changes. Запустится GitHub Actions → **Offline tests of exporter source (NO Telegram login)**. Он проверит SHA-256 архива и запустит криптографические и статические тесты без доступа к аккаунтам.

SHA-256 ожидаемого ZIP: `6aa2c1c5805b6044b98a7182b5dcd3cbcd80683429cd1d916779463b047fcef5`

После офлайн-проверок отдельно настраивается сборка тестового Android APK с официальной TDLib и Telegram Test DC. Главный аккаунт до завершения проверки не подключаем.

Подробнее: [SECURITY.md](SECURITY.md).

**Ограничения:** нулевой риск ограничения Telegram и утечек никто гарантировать не может. Нужны тесты на реальном Android, сетевой аудит и независимая проверка безопасности.
