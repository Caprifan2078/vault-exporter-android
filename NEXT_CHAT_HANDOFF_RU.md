## ВОТ ЧЕГО ХОЧЕТ ПОЛЬЗОВАТЕЛЬ
Один понятный APK: пользователь устанавливает, входит в Telegram, выбирает чат, нажимает «Скачать переписку», получает полный архив доступной истории и вложений на телефоне. Читалка — ОТДЕЛЬНЫЙ законченный проект пользователя, в данный APK не интегрировать. Ни Termux, ни команд, ни ручного api_id/api_hash для конечных пользователей. Безопасность аккаунта и конфиденциальность первичны, скорость и удобство вторичны. Пользователь ценит реальные APK и работающие пользовательские сценарии, а НЕ отчёты «все тесты пройдены».

## ЧТО ИМЕННО ПРОВЕРЯЕТ КНОПКА «МИЛЛИОН СЛОВ + КРУЖКИ, ГОЛОСОВЫЕ И СТИКЕРЫ»
Только служебный офлайн стресс-тест, НЕ будущий основной пользовательский интерфейс. Генерируются синтетические ответы TDLib с >1 млн слов, WebP/TGS, OGG voice, MP4 round-video, WAV audio, JPG, animation, documents, link preview with 2 attachments. Через тот же ExportEngine создаётся зашифрованный .tva, затем MegaArchiveVerifier заново читает сообщения, медиа и форматы. НЕ утверждать, что имитатор доказал реальное взаимодействие с серверами Telegram.

## ВАЖНЫЕ ПРАВИЛА БЕЗОПАСНОСТИ
- Не подключать личный Telegram аккаунт пользователя и не просить коды, пароли или API секреты в чат.
- Не пользоваться чужими Telegram API ключами для основной (production) сборки.
- Не тестировать обходы FloodWait, лимитов Telegram, содержимое с запретом сохранения/секретные чаты.
- Ни третьих серверов, ни телеметрии, ни публичной публикации личных переписок или ключей.
- Промежуточные файлы шифруются через Android Keystore; незашифрованную копию в TDLib приватном кэше нужно удалять и подтверждать удаление; при сбое STOP + явное предупреждение.
- Готовый HTML ZIP нешифрован — только по явному решению пользователя; основной приватный архив .tva зашифрован.
- Нулевой риск санкций от Telegram обещать нельзя.
- Без официального app api_id/api_hash и подтверждённого реального Android подключения сетевую production-версию не объявлять готовой.

## БОЛЬШИЕ АРХИВЫ: ЧТО УЖЕ ОПТИМИЗИРОВАНО
История читается порциями по 100 и сохраняется с контрольными точками, большие файлы шифруются потоком, финальные индексы и медиа не грузятся целиком в память. Медиа в финальной ZIP-обёртке пишется без повторной тяжёлой компрессии, текст сжимается. Есть предварительная проверка диска (~двойной размер нового файла + резерв) и предупреждение пользователю. Добавлены несколько файлов в одном сообщении, разные форматы аудио и защита от пропуска неизвестного типа Telegram данных. 100 ГБ и настоящая облачная история на Android НЕ проверены; могут потребоваться архитектурные изменения, например разбиение на тома, учёт ограничений провайдеров документов, устойчивость к уничтожению Activity/фонового процесса.
